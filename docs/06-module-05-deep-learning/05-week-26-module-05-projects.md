# Week 26: Module 05 Projects

## Projects

### Class-based projects

- **CNN-Based Image Classifier**: Classify images using convolutional neural networks.
  - *Roman Urdu:* CNN se images classify karein.
- **LSTM Movie Review Sentiment Analyzer**: Predict sentiment from movie reviews using LSTM networks.
  - *Roman Urdu:* LSTM se movie reviews ka sentiment (positive/negative) pehchanein.
- **Transfer Learning (ResNet/VGG)**: Apply pre-trained models to new image classification tasks.
  - *Roman Urdu:* Pre-trained models ko naye image classification kaam par lagayein.

### Home-based projects

- **Dogs vs Cats Classification**: Build a model to classify dog and cat images.
  - *Roman Urdu:* Kutton aur billiyon ki tasveerein alag karne wala model banayein.
- **Spam Detection using Deep Learning**: Detect spam messages or emails using neural networks.
  - *Roman Urdu:* Neural networks se spam messages ya emails pakdein.
