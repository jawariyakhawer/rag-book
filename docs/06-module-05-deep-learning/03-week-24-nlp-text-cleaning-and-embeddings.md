# Week 24: NLP: Text Cleaning and Embeddings

## Text Cleaning

Preprocess textual data so models can use it.

:::info Roman Urdu
Text data ko model ke istemal ke qabil banane ke liye saaf karna.
:::

## Embeddings

Convert text into numerical vectors that capture semantic meaning. Embeddings are also the foundation of RAG, which you will build later.

:::info Roman Urdu
Text ko numbers (vectors) mein badalna jo matlab ko pakartay hain. Embeddings hi RAG ki buniyad hain jo aap aage banayenge.
:::
