# Week 23: Computer Vision

## Convolutional Neural Networks (CNNs)

Neural networks specialized for image data and feature extraction.

:::info Roman Urdu
Images ke liye khaas neural networks jo features khud nikalte hain.
:::

## Transfer Learning

Reuse pre-trained models (e.g. ResNet, VGG) for new tasks to save time and improve performance.

:::info Roman Urdu
Pehle se trained models (jaise ResNet, VGG) ko naye kaam ke liye istemal kar ke waqt bachana.
:::
