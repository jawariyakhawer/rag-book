# Week 22: Neural Network Fundamentals

## Perceptron, Forward and Backpropagation

The basic unit of neural networks and how information flows forward and weights are updated backward during learning.

:::info Roman Urdu
Neural network ki buniyadi ikai aur seekhne ke dauran information aage kaise jati hai aur weights peeche kaise update hote hain.
:::

## Activation and Loss Functions

Functions that add non-linearity and measure prediction errors to optimize the model.

:::info Roman Urdu
Wo functions jo non-linearity lati hain aur prediction ki ghalti napti hain taake model behtar ho.
:::
