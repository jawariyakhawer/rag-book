# Week 18: Random Forest and Gradient Boosting

:::info Roman Urdu
Bohat se decision trees ka ensemble jo accuracy barhata aur overfitting kam karta hai.
:::

## Gradient Boosting (XGBoost/LightGBM)

Advanced boosting algorithms for high-performance predictions.

:::info Roman Urdu
Boht tez aur taqatwar predictions ke liye advanced boosting algorithms.
