# Module 04: Machine Learning

**Weeks 15 to 21**

From the ML pipeline to supervised and unsupervised algorithms, you learn to build, evaluate and compare models on real datasets.

:::info Roman Urdu
ML pipeline se le kar supervised aur unsupervised algorithms tak, aap real datasets par models banana, evaluate karna aur compare karna seekhte hain.
:::

## Weeks in this module

- Week 15: ML Pipeline, Feature Engineering and Preprocessing
- Week 16: Train/Test Split and Linear Regression
- Week 17: Logistic Regression and Decision Trees
- Week 18: Random Forest and Gradient Boosting
- Week 19: KNN and SVM
- Week 20: Unsupervised Learning: Clustering
- Week 21: PCA and Module 04 Projects
