# Week 21: PCA and Module 04 Projects

## Principal Component Analysis (PCA)

Dimensionality reduction that simplifies data while keeping the key information.

:::info Roman Urdu
Dimensionality reduction: ahem maloomat rakhte hue data ko saada banana.
:::

## Projects

### Class-based projects

- **House Price Prediction**: Predict housing prices using regression algorithms.
  - *Roman Urdu:* Regression algorithms se ghar ki qeemat predict karein.
- **Customer Segmentation (K-Means)**: Group customers into segments by behavior and characteristics.
  - *Roman Urdu:* Customers ko unke behavior ke mutabiq groups mein baantein.
- **Loan Eligibility Prediction**: Classify loan applicants as eligible or not using supervised learning.
  - *Roman Urdu:* Supervised learning se loan applicants ko eligible/not eligible classify karein.
- **Fraud Detection Model**: Detect fraudulent transactions using classification techniques.
  - *Roman Urdu:* Classification se fraud transactions pakadna.

### Home-based projects

- **Churn Prediction**: Predict customer attrition using real-world datasets.
  - *Roman Urdu:* Real datasets se andaza lagayein ke kaun se customers chhor kar jayenge.
- **Sales Forecasting**: Forecast sales trends using machine learning models.
  - *Roman Urdu:* ML models se sales ka future trend predict karein.
- **Credit Risk Scoring Model**: Assess clients' creditworthiness using predictive modeling.
  - *Roman Urdu:* Predictive modeling se clients ki credit worthiness check karein.
- **HR Attrition Prediction**: Predict employee turnover using historical HR data.
  - *Roman Urdu:* Purane HR data se employees ke job chhorne ka andaza lagayein.
