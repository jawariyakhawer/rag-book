# Week 41: Multi-Agent Systems and Module 09 Projects

## Multi-Agent Systems

Coordinate multiple AI agents to solve collaborative tasks.

:::info Roman Urdu
Kai AI agents ko ikhatta kar ke mil jul kar kaam hal karwana.
:::

## Projects

### Class-based projects

- **AI Autonomous Data Analyst**: Build an AI agent that analyzes and reports on data automatically.
  - *Roman Urdu:* Aisa AI agent jo data ka khud tajzia kar ke report banaye.
- **Multi-Agent System (Researcher + Writer + Reviewer)**: Develop a collaborative AI system with specialized agent roles.
  - *Roman Urdu:* Alag alag kirdar wale agents ka collaborative AI system.

### Home-based projects

- **Personal AI Assistant with Tools**: Create a custom AI assistant capable of executing tasks.
  - *Roman Urdu:* Tools ke sath apna personal AI assistant banayein jo kaam kar sake.
- **Automated Email + Reporting Agent System**: Automate communication and reporting using AI agents.
  - *Roman Urdu:* AI agents se emails aur reporting automate karein.
