# AI & Data Science: Javeria Hassan Edition

A 10-month journey from Python to Agentic AI, in English and Roman Urdu.

This book follows the **AI and Data Science Syllabus** by Miss Javeria Hassan (SMIT, Saylani Mass IT Training). Every topic is explained in English and in Roman Urdu, and an AI tutor is always one click away.

| | |
|---|---|
| **Course duration** | 10 Months (could be extended to 11 months) |
| **Course level** | Beginner to Advanced |
| **Prerequisites** | Basic knowledge of programming is preferred but not mandatory. |
| **Prepared for** | Javeria Hassan |
| **Created by** | Maria Hussain |

## How this book is organized

| Module | Weeks |
|---|---|
| Course introduction and setup | Week 1 |
| Module 01: Python Foundations | Weeks 2 to 6 |
| Module 02: Python for Data Science (NumPy, Pandas, Visualization) | Weeks 7 to 10 |
| Module 03: Statistics and Math for ML | Weeks 11 to 14 |
| Module 04: Machine Learning | Weeks 15 to 21 |
| Module 05: Deep Learning | Weeks 22 to 26 |
| Module 06: MLOps | Weeks 27 to 30 |
| Module 07: Big Data and Cloud | Weeks 31 to 34 |
| Module 08: Generative AI (LLMs) | Weeks 35 to 38 |
| Module 09: Agentic AI | Weeks 39 to 41 |

Each module ends with class-based projects, home-based projects and a presentation.

## Using the AI tutor

1. Click the chat icon at the bottom corner of any page.
2. Type your question in English or Roman Urdu.
3. The tutor answers using this book's content, with examples.

:::tip Have a doubt?
Click the round chat icon in the corner of the screen and ask the AI tutor. You can ask in English or Roman Urdu, for example: "Is topic ko example ke sath samjhao".
:::
