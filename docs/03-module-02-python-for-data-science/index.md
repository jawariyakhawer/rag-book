# Module 02: Python for Data Science (NumPy, Pandas, Visualization)

**Weeks 7 to 10**

Learn the core data science toolkit: fast numerical computing with NumPy, tabular data with Pandas, cleaning messy data and telling stories with charts.

:::info Roman Urdu
Data science ke asal tools seekhein: NumPy se tez numerical computing, Pandas se tabular data, ganda data saaf karna aur charts se kahani batana.
:::

## Weeks in this module

- Week 7: NumPy and Pandas Basics
- Week 8: Data Cleaning and Missing Values
- Week 9: Merging, GroupBy and Visualization
- Week 10: Module 02 Projects
