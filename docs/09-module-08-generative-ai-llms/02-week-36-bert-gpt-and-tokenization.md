# Week 36: BERT, GPT and Tokenization

## BERT and GPT (Conceptual Understanding)

The principles behind popular NLP models: BERT reads text in both directions, GPT generates text one token at a time.

:::info Roman Urdu
Mashhoor NLP models ke usool: BERT text ko dono taraf se parhta hai, GPT ek ek token karke text likhta hai.
:::

## Tokenization

Break text into tokens so a model can process and understand it.

:::info Roman Urdu
Text ko tokens mein todna taake model use samajh sake.
:::
