# Week 1: Course Introduction and Setup

## Course intro, expectations and roadmap overview

You get the full picture of the 10-month journey: nine modules that take you from Python basics to Machine Learning, Deep Learning, MLOps, Big Data, Generative AI and Agentic AI. Each module ends with class-based and home-based projects and a presentation.

:::info Roman Urdu
Is hafte mein poore 10 mahine ka roadmap samjhaya jata hai. Nau modules hain jo Python ke basics se shuru ho kar Machine Learning, Deep Learning, MLOps, Big Data, Generative AI aur Agentic AI tak jaate hain. Har module ke end par class aur home projects hote hain aur ek presentation bhi.
:::

## Python installation and IDE setup

Install Python, set up an editor such as VS Code (or Jupyter), create a virtual environment and run your first script to confirm everything works.

:::info Roman Urdu
Python install karein, VS Code (ya Jupyter) jaisa editor set karein, virtual environment banayein aur pehli script chala kar check karein ke sab theek chal raha hai.
:::

```python
python --version
python -m venv venv
# Windows: venv\Scripts\activate     Mac/Linux: source venv/bin/activate
print("Hello, AI & Data Science!")
```
