# Module 07: Big Data and Cloud

**Weeks 31 to 34**

When data no longer fits on one machine you need distributed tools. Learn Hadoop, Spark and the basics of cloud platforms (AWS or Azure).

:::info Roman Urdu
Jab data ek machine mein na samaye to distributed tools chahiye hote hain. Hadoop, Spark aur cloud platforms (AWS ya Azure) ke basics seekhein.
:::

## Weeks in this module

- Week 31: Big Data and Hadoop
- Week 32: Apache Spark
- Week 33: Cloud (AWS or Azure)
- Week 34: Module 07 Projects
