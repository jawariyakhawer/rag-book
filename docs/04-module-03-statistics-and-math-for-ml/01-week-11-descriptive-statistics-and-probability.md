# Week 11: Descriptive Statistics and Probability

## Descriptive Statistics

Summarize data with mean, median, mode, variance and standard deviation.

:::info Roman Urdu
Mean, median, mode, variance aur standard deviation se data ka khulasa nikalna.
:::

```python
import numpy as np
x = np.array([4, 8, 6, 5, 9])
print(x.mean(), np.median(x), x.var(), x.std())
```
