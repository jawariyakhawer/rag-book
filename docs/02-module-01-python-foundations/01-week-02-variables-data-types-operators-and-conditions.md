# Week 2: Variables, Data Types, Operators and Conditions

## Variables, Data Types, Operators

Understand different data types (int, float, str, bool), declare variables, and use arithmetic, logical and comparison operators.

:::info Roman Urdu
Alag alag data types (int, float, str, bool) samjhein, variables banayein aur arithmetic, logical aur comparison operators istemal karein.
:::

```python
name = "Ali"          # str
age = 21              # int
gpa = 3.6             # float
is_student = True     # bool
print(age + 5, age > 18, age > 18 and gpa > 3.5)
```

## Conditional Statements

Use if, elif and else so your program can make decisions.

:::info Roman Urdu
if, elif aur else ke zariye program ko faislay karna sikhayein.
:::

```python
marks = 72
if marks >= 80:
    print("A")
elif marks >= 60:
    print("B")
else:
    print("Work harder")
```
